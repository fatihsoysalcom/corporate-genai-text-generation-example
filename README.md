# Corporate GenAI Text Generation Example

This example demonstrates how Generative AI (GenAI) can be used beyond traditional product development, specifically for diverse corporate functions like marketing and human resources. It uses a Large Language Model (LLM) API (OpenAI's GPT) to generate text for a social media post and an internal HR announcement. This illustrates GenAI's potential to enhance efficiency and creativity across various business departments without requiring external libraries.

## Language

`python`

## How to Run

1. Set your OpenAI API key as an environment variable: `export OPENAI_API_KEY='your_api_key_here'`
2. Run the script: `python main.py`
